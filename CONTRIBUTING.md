# Contributing

Changes should preserve the source taxonomy, inferential scope, and evidence provenance.

## Scientific changes

If a contribution changes the category mapping, project threshold, uncertainty method, heterogeneity statistic, or diagnostic definition, update the protocol and add tests.

Do not silently change the primary estimand.

## Taxonomy integrity

Perfective, corrective, and other are mutually exclusive source categories.

Do not reintroduce the former independent binary flag or phi coefficient interpretation.

## Statistical integrity

Keep the full table assumption warning visible.

If the primary project sample threshold changes, report the old and new result and update the sensitivity analysis.

Residuals and project contributions are diagnostics. Do not present them as individual project quality tests.

## Data changes

Preserve the Zenodo source identity and both checksum checks.

Do not add a synthetic fallback to the source rebuild.

## Documentation changes

Keep all headline numbers synchronized with the packaged CSV and JSON evidence.

Do not imply causal, temporal, cost, schedule, productivity, or project quality conclusions that the released design does not support.
