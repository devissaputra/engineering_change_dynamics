# Originality and Positioning Map

## Portfolio position

Engineering Management Research / Software Intensive Systems / Engineering Change.

## What this repository is

A secondary analysis of project level heterogeneity in manually classified software maintenance intent.

## What it is not

It is not:

- a new commit intent classifier;
- a reproduction of the full Trautsch et al. metric study;
- a project quality ranking;
- a causal model of maintenance behavior;
- a temporal change dynamics model.

## Distinctive contribution

The source publication primarily studies how perfective and corrective intent relate to static software metrics and warnings.

This repository asks a different question:

**How much does the manually observed maintenance intent composition vary across projects?**

The release adds:

- complete project composition evidence;
- project level uncertainty;
- an explicit contingency analysis;
- sample size sensitivity;
- primary subset residual diagnostics;
- project contribution decomposition.

## Nearest portfolio neighbors

- `technical_performance_margin_monitor`
- `requirements_evidence_triage`
- `empirical_engineering_tradespace`

This repository remains distinct in source, unit of analysis, statistical design, and software maintenance interpretation.

## Meaning of originality

Originality here means a materially distinct and reproducible secondary analysis.

It does not imply that maintenance categories, contingency analysis, Cramér's V, or commit classification are new methods.
